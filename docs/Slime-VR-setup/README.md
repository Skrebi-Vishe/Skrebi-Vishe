# Настройка трекеров SlimeVR с нуля

Пошаговый гайд для новичков по DIY‑трекерам SlimeVR первого поколения: плата **Wemos D1 Mini (ESP8266)** и датчик **BMI160**, прошивка **v0.5.4**.

**[→ Открыть гайд](https://skrebi-vishe.github.io/Skrebi-Vishe/Slime-VR-setup/)**

## Что внутри

1. Проверка, подходят ли трекеры
2. Подготовка: калибровочная коробочка, упор, программы
3. Прошивка v0.5.4 через сайт: поворот датчика, сброс старых данных, настройки
4. Калибровка по осям (6 сторон) с подсказками по консоли
5. Температурная калибровка (холодильник и фен)
6. Проверка калибровки на TCAL Checker
7. Пол в шлеме и SteamVR
8. Как правильно надеть трекеры
9. Настройка в SlimeVR
10. Калибровка в VRChat

Плюс порядок действий перед каждой игрой, частые проблемы, 3D‑схемы и модели корпусов Hyperion для 3D‑печати (комплект 8+2).

## Файлы

```
index.html                              — страница гайда
css/style.css                           — оформление
js/hyperion.js                          — 3D-модели корпусов трекера и ответвления
js/scenes.js                            — 3D-сцены: коробочка и 6 положений калибровки
js/nav.js                               — оглавление, подсветка шага, отметки «выполнено»
js/dl.js                                — скачивание моделей, копирование ника Discord
img/                                    — фотографии и кадры из видео
models/SlimeVR_Hyperion_models.zip      — модели корпусов для 3D-печати (STL)
```

3D‑сцены загружают библиотеку three.js из интернета, шрифты загружаются с Google Fonts.
